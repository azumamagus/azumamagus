## Sobre

Desenvolvedor de software com experiência em aplicações web, APIs, sistemas legados, bancos de dados e infraestrutura.

Comecei pela **administração de bancos de dados**, e essa base moldou como eu construo software: olhando dados, operação e o impacto real de cada decisão — não apenas o código.

Hoje atuo no desenvolvimento de **aplicações web, APIs RESTful, integrações e modernização de sistemas** com .NET, C#, PHP, Laravel e React.

Em paralelo, estudo **segurança ofensiva** com foco em pentest web e application security — porque quem entende como uma aplicação quebra escreve código melhor. Fora do trabalho, **game development** é meu laboratório criativo.
